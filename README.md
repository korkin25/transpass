# transpass

Офлайн-приложение для Android: вводите русскую фразу, получаете символы,
как если бы набирали её на английской раскладке тех же клавиш.

**`Привет` → `Ghbdtn`**, **`пароль` → `gfhjkm`**. Это замена раскладки, не транслитерация и не шифрование.

- Ввод всегда скрыт звёздочками, включая последний введённый символ.
- Результат скрыт по умолчанию; его можно показать и снова скрыть кнопкой.
- Кнопка копирования копирует результат, даже когда он скрыт.
- Никаких сетевых запросов, аналитики, аккаунтов и разрешения `INTERNET`.
- Введённый текст не записывается в файлы, журналы или сохранённое состояние.
- При уходе с экрана приложения результат скрывается; при остановке экрана ввод очищается.

## Android

Android 8.0 (API 26) или новее. Откройте [Actions](https://github.com/korkin25/transpass/actions),
выберите успешный запуск `Android` и скачайте артефакт `transpass-debug-apk`.
Распакуйте архив и установите `app-debug.apk`. Это тестовая сборка с debug-подписью,
не публикация в Google Play. Подпись тестовой сборки может меняться между CI-запусками;
тогда для установки понадобится удалить прежнюю сборку.

## Разработка

JDK 17+, Android SDK Platform 35 и Build Tools 35.0.0. Укажите SDK через
`ANDROID_HOME` или `sdk.dir` в локальном `local.properties`.

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.
Первая **сборка** скачивает SDK/Gradle/зависимости; **приложению** сеть не нужна.
У приложения нет сторонних runtime-зависимостей.

## Раскладка и приватность

Поддерживается направление **русская ЙЦУКЕН → английская QWERTY** с сохранением регистра.
Английские буквы, цифры, пробелы, emoji и прочие символы остаются без изменений.
Русские буквы на клавишах пунктуации преобразуются: `хъжэбюё` → `[];'.,` + обратная кавычка.
Уже введённая пунктуация не меняется: это позволяет смешивать языки без неоднозначной замены.

Копирование передаёт результат системному буферу обмена. Приложение помечает его
как чувствительные данные, но не управляет сторонней клавиатурой и приложениями,
которым ОС разрешает читать буфер. Скриншоты окна приложения заблокированы.

## Дальнейшие платформы

Сейчас реализован Android. Преобразование выделено в независимый от Android класс
`KeyboardLayout`, а тесты фиксируют соответствия. Версия для iOS пока не реализована.

## CI

Проверки и APK собираются в GitHub Actions на `ubuntu-24.04`.
После регистрации отдельного ARC runner в `pure_vps` задайте repository variable
`ANDROID_RUNNER=pure-vps-linux-x64-transpass`. Тогда push и ручные запуски перейдут
на него; SDK/JDK будут установлены автоматически на рабочий том runner.
До регистрации переменная остаётся пустой и используется GitHub-hosted runner.
Workflow не исполняет код pull request на личном self-hosted runner.
